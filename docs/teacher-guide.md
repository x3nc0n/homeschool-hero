# Homeschool Hero Parent & Teacher Guide

Welcome to **Homeschool Hero**. This guide is written for parents, co-parents, and teachers who use the system to organize day-to-day homeschool work: planning lessons, creating assignments, tracking attendance, grading student work, and keeping records ready for reporting.

Use this handbook as your “how do I do this?” reference.

![Dashboard Overview](screenshots/dashboard.png)

## 1. Getting Started

### Signing in

Homeschool Hero supports more than one sign-in method:

- **Email + password**
- **OIDC single sign-on** (such as Microsoft Entra ID, if your site owner has enabled it)
- **SAML single sign-on**

On the login page:

1. Open the Homeschool Hero web address.
2. Choose your sign-in method.
3. Enter your email and password, or continue with your organization’s sign-in provider.

If this is a brand-new installation, you may see a **first-time setup** screen instead of the normal login page.

### First-time owner setup

The first person to use a new system creates the main family account.

You will be asked for:

- Family name
- Your display name
- Email
- Password

After setup, you are signed in automatically as the owner.

### Accepting an invitation

If another parent invited you:

1. Open the invitation link.
2. Enter your email.
3. Enter your display name.
4. Create a password.
5. Submit the form to join the family workspace.

### Understanding roles

Different people may see different options:

- **Parent / Co-parent**: full household management
- **Tutor**: teaching and grading tools, but more limited family administration
- **Student viewer**: read-only, student-scoped views

### Finding your way around

The main navigation is grouped into sections:

- **Dashboard**
- **Students**
- **Academics**
- **Assignments & Grading**
- **Reports**
- **Data**
- **Settings**

Helpful built-in shortcuts:

- **Global search** in the header
- **Ctrl/Cmd + K** to jump to search quickly
- **Notifications bell** for alerts
- **Mobile bottom navigation** on small screens

### Mobile and tablet use

Homeschool Hero is designed for mobile use too. On phones and tablets, you can:

- Open the navigation drawer
- Use bottom tabs for common areas
- Upload work with the **camera**
- Pull to refresh on key pages

If your device offers it, you may also see an option to **install Homeschool Hero like an app**.

## 2. Setting Up Your Homeschool Workspace

Before you start daily work, it helps to set up a few basics.

### Add students

Go to **Students**.

1. Enter the student’s name.
2. Select **Add student**.
3. Repeat for each learner.

From the student list, you can:

- Open a student dashboard
- Edit a student name
- Remove a student if needed

### Create subjects

Go to **Subjects**.

For each subject, you can choose:

- Subject name
- Color
- **Grading mode**: points-based or percentage-based
- A custom **grade scale** or the family default

You can also set **grade categories** such as:

- Homework
- Quiz
- Test

Each category can have:

- A weight
- A “drop lowest” rule

### Build your school year and grading periods

Go to **Calendar**.

Here you can create:

- **School years**
- **Terms** (semester, quarter, trimester, or custom)
- **Grading periods**
- **Calendar events** such as holidays or closures

This is important because report cards, gradebook filters, and compliance tracking all use your academic calendar.

![Calendar Setup](screenshots/calendar.png)

### Set family-wide rules and preferences

Go to **Settings → Family**.

This page lets you manage:

- Family **state code** for compliance tracking
- Family **grade scales**
- Custom **compliance rules**
- **Maintenance mode** for planned downtime
- Interface language

This is also the best place to confirm that your family’s grading rules match your homeschool approach.

### Invite other adults

Go to **Settings → Invitations**.

You can invite:

- Co-parents
- Tutors
- Student viewers

When creating an invitation, choose:

- Email address
- Role
- Expiration window
- Student (for student-viewer invitations)

You can copy the invitation link or revoke it later.

## 4. Planning the Year: Calendar, Planner, Curriculum, and Lessons

### Calendar

The **Calendar** page is where you define the academic structure for the year.

Best uses:

- Set the school year start and end dates
- Break the year into terms
- Add grading periods
- Mark holidays and non-instructional days

### Planner

Go to **Academics → Planner** for day-by-day and week-by-week schedule management.

You can create:

- Student schedules
- Recurring schedule blocks
- Date-specific schedule overrides

Use the Planner to:

1. Choose a student.
2. Create a schedule for the correct school year.
3. Add recurring blocks by day and time.
4. Add overrides when real life changes the plan.
5. Review the daily and weekly agenda views.

This is useful for building a realistic homeschool rhythm.

### Curriculum packages

Go to **Academics → Curriculum**.

Curriculum is organized as:

**Package → Unit → Lesson**

You can:

- Create a curriculum package for a school year and subject
- Add units
- Add lessons inside each unit
- Add standards tags
- Clone a package into another school year

This is ideal when you want to reuse a strong plan from one year to the next.

### Lesson plans and pacing

Go to **Academics → Lesson Plans**.

Here you can:

- Create lesson plans for a student
- Generate lesson plans from a curriculum package
- Set pacing targets for units
- Bulk reschedule planned lessons
- Switch between **timeline** and **list** views

A practical workflow:

1. Build a curriculum package first.
2. Open **Lesson Plans**.
3. Choose the student and school year.
4. Generate lessons from the package, or create them manually.
5. Set pacing targets for major units.
6. Use the pacing view to spot lessons that are falling behind.

### Resource library

Go to **Data → Resources**.

The resource library stores:

- Files
- Links
- Notes

You can:

- Tag resources
- Add metadata
- Search and filter by type or tag
- Link resources to specific lessons

This is a great place for worksheets, reference links, printable packets, and teacher notes.

## 5. Creating Assignments

Go to **Assignments & Grading → Assignments**.

Assignments can include:

- Title
- Description
- Due date
- Subject
- Category
- Grading period
- Weight
- Maximum score
- Recurrence
- Rubric notes
- Attachment links
- Student-specific targets

### Creating an assignment

1. Open **Assignments**.
2. Fill in the assignment details.
3. Choose the subject and category.
4. Set the due date.
5. Select one or more students.
6. Save the assignment.

### Assigning work to specific students

Assignments can be targeted student by student. This helps when siblings are working at different levels.

You can also set target statuses such as:

- Assigned
- Submitted
- Graded
- Excused

### Recurring assignments

For repeated work, you can use recurrence settings such as:

- None
- Daily
- Weekly

### Answer keys

Assignments can include an **answer key** with:

- Question number
- Correct answer
- Point value
- Partial credit rules

This is especially useful when you want AI-assisted grading or faster review later.

## 6. Quizzes

Go to **Assignments & Grading → Quizzes**.

Homeschool Hero includes a built-in quiz tool.

### Creating a quiz

You can build:

- Multiple-choice questions
- Short-answer questions
- True/false questions

To create one:

1. Enter a quiz title.
2. Optionally assign a subject.
3. Add questions.
4. Save the quiz.

### Taking a quiz

On the same page, you can:

1. Choose the student.
2. Choose the quiz.
3. Enter responses.
4. Submit the quiz.

The system can score a quiz immediately when possible.

## 7. Uploading Student Work

Go to **Assignments & Grading → Uploads**.

This page is designed for quick work submission from a computer, tablet, or phone.

### Supported file types

Homeschool Hero accepts:

- PDF
- JPEG / JPG
- PNG
- HEIC / HEIF
- TIFF
- WEBP

**Maximum file size:** 25 MB per file

### Uploading work

1. Choose the student.
2. Choose the matching assignment.
3. Drag in a file, browse for one, or use **Use camera** on mobile.
4. Review the preview.
5. Select **Upload submission**.

If AI/OCR features are unavailable, the page will tell you that the upload will still be stored but routed differently.

### Resubmitting work

You can upload a **new version** of a submission.

That means:

- Older versions are preserved
- The newest version becomes the current one
- Grading and review use the current version

### Watching grading progress

After upload, the submission detail panel shows:

- Current version number
- File information
- Open file link
- Grading progress bar
- Confidence score (when available)
- Manual review reason (if needed)
- Version history

## 8. Grading and the Review Queue

### How grading works

Depending on system setup, Homeschool Hero can use:

- OCR to read uploaded work
- AI-assisted grading
- Answer-key scoring
- Manual review

A submission may move through steps such as:

- Pending
- OCR processing
- OCR complete
- AI grading
- Review needed
- Reviewed
- Final

### Review queue

Go to **Assignments & Grading → Review Queue**.

This page helps you manage work that needs human attention.

You can filter by:

- Status
- Priority
- Student
- Subject
- Search terms

You can also:

- Bulk approve items
- Bulk assign items to a reviewer

### Reviewing one item

Open a review to see:

- The uploaded image
- OCR text
- AI confidence
- AI feedback
- Answer-key suggestion
- Reviewer notes
- Review comments

From the detail page, you can:

- **Approve / save**
- **Re-grade**
- **Reject / request resubmission**
- Assign another reviewer
- Add comments for collaborators

This makes it easy to keep AI helpful without giving up parent control.

- Category weight

- Warning items

- Missing requirements

## 15. Data Tools: Imports, Exports, Backups, and Restore

### Imports

Go to **Data → Import data**.

You can import:

- Students
- Subjects
- Assignments
- Grades
- Attendance
- Curriculum packages

Recommended process:

1. Download a starter template if needed.
2. Upload your CSV or JSON file.
3. Run **Validate dry run**.
4. Fix any reported issues.
5. Run **Execute import**.

### Exports

Go to **Data → Export data**.

Export options include:

- Full family export
- Incremental export
- Entity-specific export

Available formats:

- JSON
- CSV
- ZIP bundle

ZIP exports can include PDFs and uploaded files where appropriate.

### Backups

Go to **Settings → Backups**.

This page shows:

- Backup destination
- Schedule
- Encryption readiness
- Mount validation
- History

You can also run a **manual backup**.

### Restore

Go to **Settings → Restore**.

The restore workflow is intentionally careful:

1. Choose a backup.
2. Validate the backup first.
3. Review warnings and checks.
4. Choose a **full restore** or **selective restore**.
5. Confirm the action.

The system takes a safety snapshot before restoring.

## 17. Suggested Everyday Workflows

### A simple weekly planning routine

1. Open the **Dashboard**.
2. Review upcoming assignments and pacing alerts.
3. Open **Lesson Plans** to adjust the week.
4. Check **Planner** for schedule conflicts.
5. Add or update assignments for each student.

### A simple grading routine

1. Upload student work from **Uploads**.
2. Watch for automatic grading progress.
3. Open the **Review Queue** for anything flagged.
4. Approve or adjust scores.
5. Check the **Grade Book** for updated averages.

### A simple reporting routine

1. Keep attendance current.
2. Keep assignments and grades up to date.
3. Review the **Compliance** dashboard monthly.
4. Generate **Report Cards**, **Transcripts**, or **Compliance Reports** when needed.
5. Export or back up records regularly.

## 18. Tips and Best Practices

- **Set up the calendar first.** Terms and grading periods make later reporting much smoother.
- **Use subjects and categories consistently.** Clean setup leads to cleaner gradebooks.
- **Link assignments to students.** This keeps sibling work separated clearly.
- **Add answer keys when you can.** They improve grading speed and review quality.
- **Use the camera upload on busy days.** It is one of the fastest ways to capture handwritten work.
- **Review low-confidence AI results before finalizing.** AI is a helper, not a replacement for your judgment.
- **Use the portfolio for “proof of progress.”** It is perfect for yearly reviews and state documentation.
- **Run exports and backups regularly.** Good records are most valuable when they are safe and portable.

## 19. When Something Looks Wrong

If a page is missing data or a task does not finish:

1. Refresh the page.
2. Check **System status**.
3. Look for a notice on the page about reduced AI, OCR, email, or backup availability.
4. Check **Notifications** for related alerts.
5. If needed, ask your Homeschool Hero administrator for help.
